# Portfólio Pessoal - Pedro Milan

Bem-vindo ao meu portfólio pessoal desenvolvido com Next.js, TypeScript e styled-components. Aqui você encontra meus projetos, habilidades técnicas e informações sobre minha trajetória como desenvolvedor front-end.

---

## Tecnologias Utilizadas

- **Next.js**: Framework React com SSR e SSG
- **TypeScript**: Tipagem estática para maior segurança
- **Styled Components**: CSS-in-JS para estilos dinâmicos e tema escuro
- **React Icons**: Ícones vetoriais para interface
- **React Hooks**: Gerenciamento de estado moderno e eficiente
- **I18next**: Implementação de mais línguas

---

## Funcionalidades

- Layout responsivo e acessível (WCAG 2.1)
- Tema claro e escuro com toggle
- Seções: Sobre Mim, Skills (com abas e tooltips), Projetos, Contato
- SEO otimizado com meta tags e estrutura semântica
- Animações sutis em cards e botões
- Código organizado seguindo boas práticas e Atomic Design
